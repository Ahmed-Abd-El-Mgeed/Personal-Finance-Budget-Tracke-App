# Personal Finance App

The **Personal Finance App** helps users track their daily financial activity using a clean, modern, and intuitive interface. The app allows users to manage **expenses, income, savings, and monthly budgets**, while providing **real-time analytics** with interactive charts.  

It is designed with performance and **offline-first functionality using Realm Database**, ensuring instant data access and smooth UI updates.

## 🌟 Features

- Track daily income and expenses  
- Manage budgets and savings  
- Real-time analytics with interactive charts  
- Offline-first using Realm Database  
- Secure authentication with Firebase  
- Smooth, responsive SwiftUI interface  




## ⚙️ Architecture

- **Language:** Swift, SwiftUI  
- **Architecture:** MVVM  
- **Persistence:** Realm Database  
- **Networking & Auth:** Firebase
